## QUÈ HAS DE CREAR (Part A — estructura base)

Crea aquests fitxers:

1. `backend/requirements.txt` — FastAPI, uvicorn, SQLAlchemy 2.0, pydantic 2.x,
   pydantic-settings, alembic, python-dotenv, psycopg2-binary, httpx, pytest.

2. `backend/app/__init__.py` — buit.

3. `backend/app/config.py` — classe Settings (pydantic-settings) amb:
   - DATABASE_URL (default sqlite:///./estada.db)
   - VERIFACTU_SOFTWARE_NAME (default "Estada PMS")
   - VERIFACTU_SOFTWARE_VERSION (default "0.1.0")
   - VERIFACTU_DEVELOPER_NIF
   - API_KEY (per integracions)
   - CORS_ORIGINS
   - settings = Settings() al final.

4. `backend/app/database.py` — SQLAlchemy 2.0:
   - engine (amb connect_args check_same_thread=False si sqlite)
   - SessionLocal (sessionmaker)
   - Base (DeclarativeBase)
   - get_db() dependency (yield).

5. `backend/app/models/__init__.py` — importa tots els models.

6. `backend/app/schemas/__init__.py` — buit (els schemas van a la Part B).

7. `backend/app/main.py` — FastAPI app mínima:
   - title "Estada PMS API", version "0.1.0"
   - CORS middleware
   - endpoint GET /health → {"status": "ok"}
   - include_router de health (o directe).

8. `backend/alembic.ini` — config bàsica d'Alembic (script_location = alembic).

9. `backend/alembic/env.py` — config Alembic amb Base.metadata i DATABASE_URL.

10. `backend/alembic/script.py.mako` — plantilla estàndard.

11. `backend/alembic/versions/.gitkeep` — buit.
