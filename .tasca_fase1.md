Estàs treballant al projecte **Estada**, el PMS (Property Management System) hoteler
de l'ecosistema Conceptes. El directori del projecte és `/mnt/d/projectes/Estada`.

La guia d'implementació completa és a:
`/mnt/d/projectes/Estada/Estada_guia_implementacio.md`

Llegeix-la abans de començar. Les seccions que necessites són:
- Secció 4: Estructura del repositori
- Secció 5: Model de dades (SQLAlchemy) — ENUMS + MODELS
- Secció 12: VeriFactu (FiscalRecord + FiscalSequence + hash chaining)

## Què has de crear (Fase 1: Estructura i model)

### 1. Estructura de directoris
Crea l'estructura segons la secció 4 de la guia:
```
backend/
├─ app/
│  ├─ __init__.py
│  ├─ main.py                  # FastAPI app + routers (buit de moment, només l'app)
│  ├─ config.py                # Settings (env vars): DB, Redis, API keys, VeriFactu
│  ├─ database.py              # engine + SessionLocal + Base
│  ├─ models/
│  │  ├─ __init__.py
│  │  └─ models.py             # Tots els models SQLAlchemy (secció 5)
│  ├─ schemas/
│  │  ├─ __init__.py
│  │  └─ schemas.py            # Pydantic schemas
│  ├─ api/
│  │  ├─ __init__.py
│  │  └─ routes/
│  │     └─ __init__.py
│  ├─ services/
│  │  ├─ __init__.py
│  │  └─ fiscal_service.py     # VeriFactu hash chaining (secció 12)
│  └─ utils/
│     ├─ __init__.py
│     └─ helpers.py            # uuid_pk, generate_code, etc.
├─ requirements.txt
└─ .env.example
```

### 2. config.py
Settings amb pydantic-settings. Camps: DATABASE_URL, REDIS_URL, JWT_SECRET,
JWT_ALGORITHM, ACCESS_TOKEN_EXPIRE_MINUTES, POS_API_KEY, ARIADNA_API_KEY,
VERIFACTU_SOFTWARE_NAME, VERIFACTU_SOFTWARE_VERSION, VERIFACTU_DEVELOPER_NIF,
VERIFACTU_CERTIFICATE_SERIAL. Carrega des de variables d'entorn amb prefix o sense.

### 3. database.py
engine (SQLite per dev, com Comanda), SessionLocal, Base (DeclarativeBase).

### 4. models/models.py — TOTS els models de la secció 5
ENUMS: Role, ReservationStatus, ReservationSource, RoomStatus, FolioStatus,
FolioItemType, PaymentStatus, HousekeepingTaskType, TaskStatus, IntegrationType.

MODELS (amb camps, relacions i índexs exactes de la guia):
Tenant, User, Property, RoomType, Room, RatePlan, Rate, Inventory, Guest,
Reservation, ReservationNight, Folio, FolioItem, Payment, HousekeepingTask,
Integration, WebhookEvent, AuditLog, OutboxEvent.

A més, de la secció 12: FiscalRecord i FiscalSequence.

Utilitza `uuid_pk` (UUID com a clau primària) i `generate_code` per als codis
llegibles (mateix patró que Comanda). Timestamps `created_at`/`updated_at` amb
`server_default=func.now()`.

### 5. services/fiscal_service.py — VeriFactu hash chaining (secció 12)
Implementa el servei de hash chaining SHA-256: cada FiscalRecord enllaça amb
l'anterior mitjançant el camp `previous_hash`. Funció per calcular el hash d'un
registre i per verificar la cadena completa.

### 6. schemas/schemas.py
Pydantic v2 schemas per a tots els models (Create/Read/Update segons convingui).
Com a mínim: Property, RoomType, Room, RatePlan, Rate, Inventory, Guest,
Reservation, Folio, FolioItem, Payment, HousekeepingTask, FiscalRecord.

### 7. requirements.txt
fastapi, uvicorn, sqlalchemy, pydantic, pydantic-settings, alembic, python-jose
o pyjwt, passlib, python-multipart, redis (opcional), email-validator.

### 8. .env.example
Totes les variables d'entorn amb valors d'exemple (sense secrets reals).
