## 1. backend/app/config.py
Classe Settings (pydantic-settings) amb:
- DATABASE_URL: str = "sqlite:///./estada.db"
- VERIFACTU_SOFTWARE_NAME: str = "Estada PMS"
- VERIFACTU_SOFTWARE_VERSION: str = "0.1.0"
- VERIFACTU_DEVELOPER_NIF: str = ""
- API_KEY: str = ""
- CORS_ORIGINS: list[str] = ["*"]
- model_config = SettingsConfigDict(env_file=".env", extra="ignore")
- settings = Settings() al final.

## 2. backend/app/database.py
SQLAlchemy 2.0:
- engine = create_engine(settings.DATABASE_URL, connect_args={"check_same_thread": False} si sqlite)
- SessionLocal = sessionmaker(bind=engine, autoflush=False, autocommit=False)
- class Base(DeclarativeBase): pass
- def get_db(): yield SessionLocal() amb try/finally close.

## 3. backend/app/main.py
